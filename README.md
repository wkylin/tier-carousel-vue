# Vue Tier Carousel

A minimal standalone Vue 3 project extracted from a larger loyalty page.

It demonstrates:

- click-to-select tier behavior
- pointer-based mouse/touch drag behavior
- touch-friendly vertical page scrolling with horizontal carousel gestures
- transition fallback cleanup to avoid locked interaction state
- native `<button>` keyboard support for Tab, Enter, and Space

## Run

```bash
pnpm install
pnpm dev
```

## Scripts

```bash
pnpm dev
pnpm build
pnpm type:check
pnpm lint
pnpm format
```
